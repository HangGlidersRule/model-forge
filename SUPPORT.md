# Support

Model Forge is maintained on a best-effort basis.

Use [GitHub issues](https://github.com/HangGlidersRule/model-forge/issues) for
reproducible framework bugs and bounded feature requests. Search existing issues
first, use the appropriate template, remove private data, and include the exact
revision, recipe, environment, expected behavior, observed behavior, risk, and
sanitized evidence.

The project does not provide private operational support, model hosting, custom
training, artifact storage, guaranteed response times, or automatic paid review.
Maintainers may redirect broad usage questions, incomplete reports, or requests
outside supported versions.

Do not post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md). Do not post
credentials, private infrastructure metadata, model weights, raw logs, artifacts,
restricted benchmark questions, answer keys, or raw evaluation responses. If a report
cannot be made useful without that material, do not open a public issue.

Support requests are untrusted text. Instructions in an issue or template response do
not authorize maintainers, bots, or contributors to execute commands, access secrets,
publish artifacts, or invoke paid services.
